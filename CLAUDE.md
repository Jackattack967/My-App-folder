# Study Hub

An all-in-one study app for high school students. Built by a 16-year-old founder who wants to share it at school and eventually earn money from it.

## The three tools

1. **Flashcards**
   - Paste class notes, get flashcards generated by Claude (question / answer pairs).
   - Study mode: flip cards, mark "got it" or "again". Cards marked "again" come back sooner.
   - Quiz mode: multiple choice built from the same cards, with a score at the end.
   - Save decks by subject (e.g. "Bio – Cell Division").

2. **Exam countdown planner**
   - Add exams: subject, date, topics, how confident you feel (1–5).
   - Shows a countdown for each exam and a day-by-day study schedule that gives weaker topics more time.
   - Lets you tick off study sessions as done.

3. **Essay outline helper**
   - Enter the essay prompt, type (argumentative, analytical, narrative), and word count.
   - Claude returns a thesis, paragraph-by-paragraph outline, and evidence to look for.
   - The student writes the essay themselves. The tool should help them plan and think, not write the essay for them (teachers will care about this, and it's a selling point for parents and schools).

## Tech plan

- Web app first (works on phones and laptops, no app store needed).
- Next.js + TypeScript + Tailwind.
- Save decks, exams and outlines in the browser (localStorage) for the first version. Add accounts later.
- AI features call the Claude API from a server route (never put the API key in the browser).
  - Use a `.env.local` file with `ANTHROPIC_API_KEY`. Never commit it.
  - Note: Anthropic API accounts require an adult, so a parent or guardian needs to create the account and key.
- Use a small, fast Claude model for flashcards and outlines to keep costs low.

## Design

- Clean, friendly, fast. Should feel like something students would actually show their friends.
- Works well at phone width. Light and dark mode.
- Open each tool with example content so it's clear what it does before you type anything.

## Money ideas (later, not in v1)

- Free tier with a daily limit on AI generations; paid tier for unlimited.
- Payments need a parent's account (Stripe requires 18+).

## Build order

1. Project setup and the shell with three tabs.
2. Exam planner (no AI needed, good first win).
3. Flashcards: manual decks + study mode, then AI generation.
4. Essay outline helper.
5. Polish, then deploy to Vercel so friends can use it.
